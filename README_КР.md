АЛГОРИТМЫ СОРТИРОВКИ 
1) Блочная (корзинная) сортировка — это алгоритм, который распределяет элементы исходного массива на несколько блоков (корзин) в зависимости от диапазона их значений. После этого каждая корзина сортируется отдельно (либо тем же методом рекурсивно, либо другим алгоритмом, например, вставками), и отсортированные корзины объединяются обратно в один массив.
Принцип работы:
1. Определяется количество корзин (например, по диапазону значений элементов).
2. Каждый элемент помещается в корзину согласно функции распределения.
3. Содержимое каждой корзины сортируется индивидуально.
4. Корзины соединяются в порядке увеличения диапазона.
