ВАРИАНТ 16. Реализуйте три вида обхода бинарного дерева (preorder, inorder, postorder).

1) Анализ алгоритмов:
1. class TreeNode представляет отдельный узел бинарного дерева.
2. Конструктор TreeNode(int val) инициализирует узел заданным значением и устанавливает дочерние ссылки в null.
3. public class BinaryTreeTraversal cодержит методы для трёх видов обхода и метод main для демонстрации
4. Метод preorder(TreeNode root)
Порядок: корень → левое поддерево → правое поддерево.
Базовый случай: если узел null, рекурсия завершается.
Шаги:
Выводим значение текущего узла (root.val).
Рекурсивно вызываем preorder для левого поддерева.
Рекурсивно вызываем preorder для правого поддерева.
5. Метод inorder(TreeNode root)
Порядок: левое поддерево → корень → правое поддерево.
Базовый случай: если узел null, рекурсия завершается.
Шаги:
Рекурсивно обходим левое поддерево.
Выводим значение текущего узла.
Рекурсивно обходим правое поддерево.
Примечание: для бинарного поискового дерева (BST) inorder обход выдаёт значения в возрастающем порядке.
6. Метод postorder(TreeNode root)
Порядок: левое поддерево → правое поддерево → корень.
Базовый случай: если узел null, рекурсия завершается.
Шаги:
Рекурсивно обходим левое поддерево.
Рекурсивно обходим правое поддерево.
Выводим значение текущего узла.
7. Метод main(String[] args)
Создаёт бинарное дерево с корнем 1 и дочерними узлами по схеме выше.
Вызывает все три метода обхода и выводит результаты с пояснениями.
После каждого обхода добавляет перевод строки (println()) для читаемости.

2) Временная сложность: O(n), где n — количество узлов в дереве
3) Почему: Это связано с тем, что каждый узел дерева посещается ровно один раз, а операции, выполняемые при посещении узла (например, вывод значения или рекурсивный вызов), выполняются за константное время.


КОНТРОЛЬНЫЙ ВОПРОС №5
Опишите стратегию «разделяй и властвуй» на примере алгоритма сортировки слиянием

Суть стратегии «разделяй и властвуй»: сложную задачу разбивают на более мелкие подзадачи того же типа, решают их независимо, а затем объединяют результаты для получения итогового решения.
Как это работает в сортировке слиянием:
1) Разделение:
Массив рекурсивно делят пополам, пока не получат подмассивы из одного элемента (которые по определению упорядочены):
[5, 2, 8, 1, 9]→[5, 2] ∣ [8, 1, 9]→[5] ∣ [2] ∣ [8] ∣ [1, 9]→…
2) Решение подзадач
Каждый одноэлементный подмассив считается отсортированным. Рекурсия «разворачивается» обратно, начиная с самых мелких частей.
3) Слияние
Отсортированные подмассивы попарно объединяют в новый упорядоченный массив:
-Сравнивают первые элементы двух подмассивов.
-Меньший элемент добавляют в результат и сдвигают указатель в его подмассиве.
-Повторяют, пока не исчерпают оба подмассива.

Пример слияния [2, 5] и [1, 8, 9]
-Сравниваем 2 и 1 → берём 1.
-Сравниваем 2 и 8 → берём 2.
-Сравниваем 5 и 8 → берём 5.
-Остаётся [8, 9] → добавляем их.
Итог: [1, 2, 5, 8, 9].
