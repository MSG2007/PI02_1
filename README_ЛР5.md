КОНТРОЛЬНЫЙ ВОПРОС №5
Опишите стратегию «разделяй и властвуй» на примере алгоритма сортировки слиянием

Суть стратегии «разделяй и властвуй»: сложную задачу разбивают на более мелкие подзадачи того же типа, решают их независимо, а затем объединяют результаты для получения итогового решения.
Как это работает в сортировке слиянием:
1) Разделение:
Массив рекурсивно делят пополам, пока не получат подмассивы из одного элемента (которые по определению упорядочены):
[5, 2, 8, 1, 9]→[5, 2] ∣ [8, 1, 9]→[5] ∣ [2] ∣ [8] ∣ [1, 9]→…
2) Решение подзадач
Каждый одноэлементный подмассив считается отсортированным. Рекурсия «разворачивается» обратно, начиная с самых мелких частей.
3) Слияние
Отсортированные подмассивы попарно объединяют в новый упорядоченный массив:
-Сравнивают первые элементы двух подмассивов.
-Меньший элемент добавляют в результат и сдвигают указатель в его подмассиве.
-Повторяют, пока не исчерпают оба подмассива.

Пример слияния [2, 5] и [1, 8, 9]
-Сравниваем 2 и 1 → берём 1.
-Сравниваем 2 и 8 → берём 2.
-Сравниваем 5 и 8 → берём 5.
-Остаётся [8, 9] → добавляем их.
Итог: [1, 2, 5, 8, 9].
