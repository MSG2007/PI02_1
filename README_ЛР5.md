ВАРИАНТ 16. Реализуйте три вида обхода бинарного дерева (preorder, inorder, postorder).

I) Анализ алгоритма:
1. Представляем отдельный узел бинарного дерева: class TreeNode.
2. Конструктор TreeNode(int val) инициализирует узел заданным значением и устанавливает дочерние ссылки в null.
3. Методы для трёх видов обхода и метод main для демонстрации содержатся в: public class BinaryTreeTraversal.
4. Задаётся метод для preorder обхода: public static void preorder(TreeNode root).
   Проверяется базовый случай: если узел null, то выход из рекурсии: if (root==null).
   Выводим значение текущего узла: System.out.print(root.val + " ").
   Рекурсивно вызываем preorder(root.left) для левого поддерева.
   Рекурсивно вызываем preorder(root.right) для правого поддерева.
5. Задаётся метод для inorder обхода: public static void inorder(TreeNode root).
   Проверяется базовый случай: если узел null ,то выход из рекурсии: if (root==null).
   Рекурсивно обходим левое поддерево: inorder(root.left).
   Выводим значение текущего узла: System.out.print(root.val + " ").
   Рекурсивно обходим правое поддерево: inorder(root.right).
6. Задаётся метод для postorder обхода: public static void postorder(TreeNode root).
   Проверяется базовый случай: если узел null, то выход из рекурсии: if (root==null).
   Рекурсивно обходим левое поддерево: postorder(root.left).
   Рекурсивно обходим правое поддерево: postorder(root.right).
   Выводим значение текущего узла: System.out.print(root.val + " ").
8. Задаётся основной метод для демонстрации работы обходов: public static void main(String[] args).
   Создаётся бинарное дерево с корнем 1 и дочерними узлами.
   Вызываютя все три метода обхода (preorder(root)/inorder(root)/postorder(root)) и выводятся результаты с пояснениями.
   После каждого обхода добавляется переход на новую строку (println()) для читаемости.

II) Временная сложность: O(n), где n — количество узлов в дереве
III) Почему O(n): Это связано с тем, что каждый узел дерева посещается ровно один раз(для каждого посещения: выполняется O(1) работы (проверка null, вывод значения); делаются 2 рекурсивных вызова (но они ведут к поддеревьям)), и операции, выполняемые при посещении узла выполняются за константное время.

КОНТРОЛЬНЫЙ ВОПРОС №5
Опишите стратегию «разделяй и властвуй» на примере алгоритма сортировки слиянием

Суть стратегии «разделяй и властвуй»: сложную задачу разбивают на более мелкие подзадачи того же типа, решают их независимо, а затем объединяют результаты для получения итогового решения.
Как это работает в сортировке слиянием:
1) Разделение:
Массив рекурсивно делят пополам, пока не получат подмассивы из одного элемента (которые по определению упорядочены):
[5, 2, 8, 1, 9]→[5, 2] ∣ [8, 1, 9]→[5] ∣ [2] ∣ [8] ∣ [1, 9]→…
2) Решение подзадач
Каждый одноэлементный подмассив считается отсортированным. Рекурсия «разворачивается» обратно, начиная с самых мелких частей.
3) Слияние
Отсортированные подмассивы попарно объединяют в новый упорядоченный массив:
-Сравнивают первые элементы двух подмассивов.
-Меньший элемент добавляют в результат и сдвигают указатель в его подмассиве.
-Повторяют, пока не исчерпают оба подмассива.

Пример слияния [2, 5] и [1, 8, 9]
-Сравниваем 2 и 1 → берём 1.
-Сравниваем 2 и 8 → берём 2.
-Сравниваем 5 и 8 → берём 5.
-Остаётся [8, 9] → добавляем их.
Итог: [1, 2, 5, 8, 9].
