ВАРИАНТ 13. Жадный алгоритм для задачи о распределении ресурсов.
Задача: реализовать жадный алгоритм для оптимального распределения ресурсов среди проектов.
Требования:
- Каждый проект имеет требуемый ресурс и приносит прибыль
- Общий объем ресурсов ограничен
- Выбрать проекты для максимизации прибыли
Входные данные:
Проекты: {(ресурс=10, прибыль=50), (ресурс=15, прибыль=80), (ресурс=20, прибыль=90), (ресурс=8, прибыль=40)}
Общий ресурс: 40



КОНТРОЛЬНЫЙ ВОПРОС
13. Табу-поиск
Объясните концепцию табу-листа в алгоритме табу-поиска. Какую роль он играет?
Табу-лист в алгоритме табу-поиска — это структура данных (обычно очередь ограниченного размера), где хранятся недавние решения или ходы, которые временно запрещено повторять. Его главная цель — предотвратить зацикливание алгоритма в локальных оптимумах путём исключения недавно проверенных вариантов. Таким образом, алгоритм вынужден искать новые пути решения проблемы, увеличивая шансы на обнаружение глобального оптимального решения. Табу‑лист реализует краткосрочную память алгоритма: он хранит лишь ограниченное число последних ходов (размер списка — настраиваемый параметр) и старые записи постепенно вытесняются новыми. Табу-лист позволяет расширить пространство поиска и избежать преждевременной остановки процесса оптимизации.
