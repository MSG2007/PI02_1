Параметры нейронной сети

  • Функция активации (скрытые слои): ReLU (Rectified Linear Unit)
    • Формула: f(x) = max(0, x)
    • Применение: Вводит нелинейность в модель, позволяет сети обучаться сложным зависимостям между признаками спама
  • Функция активации (выходной слой): Softmax
    • Назначение: Преобразует выходы в вероятности для двух классов (спам/не спам)
    • Формула: σ(z)ᵢ = e^(zᵢ) / Σ e^(zⱼ)
  • Оптимизатор: Adam (Adaptive Moment Estimation)
    • Скорость обучения: 0.0005 (с адаптивным снижением)
    • Преимущества: Комбинирует преимущества momentum и RMSprop, обеспечивает стабильное обучение
  • Функция потерь: Sparse Categorical Crossentropy
    • Применение: Для многоклассовой классификации с целыми метками классов

5 Основных алгоритмов в проекте

1️⃣ Adam (Adaptive Moment Estimation)

  • Где используется: Оптимизатор при компиляции модели (optimizer=Adam(learning_rate=0.0005))
  • Для чего: Адаптивное обновление весов нейронной сети для минимизации функции потерь
  • Ключевые параметры:
    • learning_rate = 0.0005 (скорость обучения)
    • beta_1 = 0.9 (экспоненциальное среднее градиентов)
    • beta_2 = 0.999 (экспоненциальное среднее квадратов градиентов)
  • Временная сложность: O(n·m) где n - количество параметров, m - размер батча
    • На каждом шаге требуется 2 вычисления момента (средние значения)
    • Дополнительная память: O(n) для хранения первого и второго момента
  • Формулы обновления:
    • m_t = β₁·m_{t-1} + (1-β₁)·g_t
    • v_t = β₂·v_{t-1} + (1-β₂)·g_t²
    • θ_t = θ_{t-1} - α·m_t / (√v_t + ε)

2️⃣ ReLU (Rectified Linear Unit)

  • Где используется: Функция активации скрытых слоев (model.add(Activation('relu')))
  • Для чего: Вводит нелинейность в сеть, позволяя ей изучать сложные закономерности в данных спама
  • Математическое определение: f(x) = max(0, x)
    • Если x > 0, то f(x) = x
    • Если x ≤ 0, то f(x) = 0
  • Преимущества:
    • Вычислительно эффективна - простое пороговое значение
    • Хорошо справляется с проблемой исчезающих градиентов
    • Инициирует разреженность активаций нейронов
  • Временная сложность: O(n) где n - количество нейронов
    • На практике: одна операция (max) на нейрон
    • Обратный проход: одна условная операция на нейрон
  • Производная (для обратного распространения):
    • f'(x) = 1, если x > 0
    • f'(x) = 0, если x ≤ 0

3️⃣ Softmax

  • Где используется: Функция активации выходного слоя (model.add(Activation('softmax')))
  • Для чего: Преобразует выходы нейронов в вероятности для каждого класса (спам/не спам)
  • Формула: σ(z)_i = e^(z_i) / Σⱼ e^(z_j)
    • z_i - выход нейрона для класса i
    • Результат: вероятности, сумма которых = 1
  • Пример: Если выходы [2.0, 1.0]:
    • e^2.0 = 7.389, e^1.0 = 2.718
    • σ₁ = 7.389 / (7.389 + 2.718) = 0.731 (73.1% - спам)
    • σ₂ = 2.718 / (7.389 + 2.718) = 0.269 (26.9% - не спам)
  • Временная сложность: O(k) где k - количество классов (2 в нашем случае)
    • Одна операция экспоненты на класс
    • Одна операция нормализации
    • Итого: очень быстро даже для больших k
  • Применение: Всегда используется с Sparse Categorical Crossentropy loss

4️⃣ L2 Регуляризация

  • Где используется: В каждом Dense слое (kernel_regularizer=tf.keras.regularizers.l2(0.001))
  • Для чего: Предотвращает переобучение, штрафуя большие веса сети
  • Формула добавления к потерям: Loss_total = Loss_основной + λ·Σ(w²)
    • λ = 0.001 (коэффициент регуляризации)
    • w - веса нейронной сети
    • Σ(w²) - сумма квадратов всех весов
  • Эффект:
    • Веса остаются маленькими и стабильными
    • Модель становится более "гладкой" и обобщаемой
    • Уменьшается переобучение на тренировочных данных
  • Временная сложность: O(n) где n - количество параметров
    • Добавляется вычисление суммы квадратов весов
    • Минимальное влияние на производительность
    • На практике: < 1% дополнительных вычислений
  • Градиент для обновления весов: ∂Loss/∂w = ∂Loss_основной/∂w + 2λw
    • Дополнительный член 2λw "притягивает" веса к нулю

5️⃣ StandardScaler (Стандартизация признаков)

  • Где используется: При подготовке данных перед обучением (scaler = StandardScaler(); X_train = scaler.fit_transform(X_train))
  • Для чего: Нормализует входные признаки к одинаковой шкале, улучшая сходимость и обучение
  • Формула преобразования: x_norm = (x - μ) / σ
    • μ - среднее значение признака на тренировочной выборке
    • σ - стандартное отклонение признака
    • Результат: среднее = 0, стд. отклонение = 1
  • Пример для признака "количество ссылок":
    • Исходные значения: [0, 1, 5, 3, 2, 10]
    • Среднее: 3.5, Стд. отклонение: ≈ 3.2
    • Нормализованные: [-1.09, -0.78, 0.47, -0.16, -0.47, 2.03]
  • Преимущества:
    • Ускоряет обучение нейронной сети (более быстрая сходимость)
    • Улучшает стабильность оптимизатора Adam
    • Предотвращает доминирование признаков с большими значениями
    • Необходимо использовать ТОЛЬКО параметры обучающего набора
  • Временная сложность: O(n·m) где n - кол-во образцов, m - кол-во признаков
    • Вычисление среднего: O(n·m)
    • Вычисление стд. отклонения: O(n·m)
    • Применение преобразования: O(n·m)
    • Применение на тесте: O(n·m)
  • Критическое замечание: Scaler обучается ТОЛЬКО на тренировочных данных, затем применяется к валидации и тесту!

📝 Исходный код нейронной сети

⚠️ Примечание: Этот код использует реальный датасет 'dataset_prob.csv' с 20,000 образцами. Он должен быть выполнен в окружении Python с установленными TensorFlow, Keras, scikit-learn и pandas.
import numpy as np import pandas as pd import tensorflow as tf from sklearn.model_selection import train_test_split from sklearn.preprocessing import StandardScaler from sklearn.metrics import classification_report, confusion_matrix from tensorflow.keras.models import Sequential from tensorflow.keras.layers import Dense, Activation, Dropout from tensorflow.keras.optimizers import Adam from tensorflow.keras.callbacks import ReduceLROnPlateau import matplotlib.pyplot as plt import seaborn as sns import joblib # Фиксация случайности для воспроизводимости np.random.seed(42) tf.random.set_seed(42) print("TensorFlow version:", tf.__version__) print("=" * 60) # 1. ЗАГРУЗКА И ПОДГОТОВКА ДАННЫХ print("1. Загрузка данных...") dataset = pd.read_csv('dataset_prob.csv') # Определяем признаки и целевую переменную feature_columns = ['num_links', 'num_words', 'has_offer', 'sender_score', 'all_caps'] target_column = 'is_spam' X = dataset[feature_columns].apply(pd.to_numeric, errors='coerce').fillna(0).values Y = dataset[target_column].map({0: 0, 1: 1}).fillna(0).values print(f"Размер датасета: {X.shape[0]} образцов, {X.shape[1]} признаков") print(f"Распределение классов:\n{pd.Series(Y).value_counts().sort_index()}") # 2. РАЗДЕЛЕНИЕ НА ОБУЧЕНИЕ/ВАЛИДАЦИЮ/ТЕСТ (60%/20%/20%) print("\n2. Разделение данных...") X_train_full, X_test, Y_train_full, Y_test = train_test_split( X, Y, test_size=0.2, random_state=42, stratify=Y ) X_train, X_val, Y_train, Y_val = train_test_split( X_train_full, Y_train_full, test_size=0.25, random_state=42, stratify=Y_train_full ) # 3. НОРМАЛИЗАЦИЯ ПРИЗНАКОВ (StandardScaler) print("\n3. Нормализация...") scaler = StandardScaler() X_train = scaler.fit_transform(X_train) # Обучение на тренировочном наборе X_val = scaler.transform(X_val) # Применение к валидации X_test = scaler.transform(X_test) # Применение к тесту print(f"Обучающая выборка: {X_train.shape[0]} образцов") print(f"Валидационная выборка: {X_val.shape[0]} образцов") print(f"Тестовая выборка: {X_test.shape[0]} образцов") # 4. ПАРАМЕТРИЗОВАННАЯ МОДЕЛЬ С ReLU И DROPOUT def create_spam_model(input_dim=5, hidden_units=[12, 6], dropout_rate=0.2, l2_reg=0.001): """ Создает нейронную сеть для классификации спама Args: input_dim: количество входных признаков hidden_units: список размеров скрытых слоев dropout_rate: вероятность dropout l2_reg: коэффициент L2-регуляризации """ model = Sequential() # Первый скрытый слой с ReLU активацией model.add(Dense( hidden_units[0], input_shape=(input_dim,), kernel_initializer='he_uniform', kernel_regularizer=tf.keras.regularizers.l2(l2_reg) # L2 регуляризация )) model.add(Activation('relu')) # ReLU функция активации model.add(Dropout(dropout_rate)) # Dropout для предотвращения переобучения # Дополнительные скрытые слои for units in hidden_units[1:]: model.add(Dense( units, kernel_initializer='he_uniform', kernel_regularizer=tf.keras.regularizers.l2(l2_reg) )) model.add(Activation('relu')) model.add(Dropout(dropout_rate)) # Выходной слой с Softmax активацией model.add(Dense(2, kernel_regularizer=tf.keras.regularizers.l2(l2_reg))) model.add(Activation('softmax')) # Softmax для вероятностей return model # 5. КОМПИЛЯЦИЯ МОДЕЛИ print("\n4. Создание и компиляция модели...") model = create_spam_model( input_dim=X.shape[1], hidden_units=[12, 6], dropout_rate=0.2, l2_reg=0.001 ) model.compile( loss='sparse_categorical_crossentropy', optimizer=Adam(learning_rate=0.0005), # Adam оптимизатор metrics=['accuracy'] ) model.summary() # 6. CALLBACK'и ДЛЯ КОНТРОЛЯ ОБУЧЕНИЯ callbacks = [ ReduceLROnPlateau( # Снижение скорости обучения если потери не улучшаются monitor='val_loss', factor=0.5, patience=5, min_lr=1e-7, verbose=1 ) ] # 7. ОБУЧЕНИЕ МОДЕЛИ print("\n5. Обучение модели...") history = model.fit( X_train, Y_train, batch_size=128, epochs=100, verbose=1, validation_data=(X_val, Y_val), callbacks=callbacks ) # 8. ОЦЕНКА НА ТЕСТОВОЙ ВЫБОРКЕ print("\n6. Оценка на тестовой выборке...") test_loss, test_accuracy = model.evaluate(X_test, Y_test, verbose=0) print(f"Test Loss: {test_loss:.4f}") print(f"Test Accuracy: {test_accuracy:.4f} ({test_accuracy*100:.2f}%)") # 9. ПОДРОБНЫЙ АНАЛИЗ ПРЕДСКАЗАНИЙ print("\n7. Подробный анализ предсказаний...") probs = model.predict(X_test, verbose=0) pred_classes = np.argmax(probs, axis=1) labels = ['Не спам', 'Спам'] # Classification Report print("\nClassification Report:") print(classification_report(Y_test, pred_classes, target_names=labels, digits=4)) # 10. СОХРАНЕНИЕ МОДЕЛИ И SCALER'а print("\n8. Сохранение модели...") model.save('spam_classifier_model.h5') joblib.dump(scaler, 'scaler.pkl') print("✅ Модель и scaler сохранены!")

Комментарии к коду:

  • Разделение данных 60/20/20: 12000 образцов для обучения, 4000 для валидации, 4000 для тестирования
  • He-uniform инициализация: Оптимальна для ReLU активации, предотвращает исчезновение градиентов
  • Dropout 0.2: Отключает 20% нейронов случайно для регуляризации
  • ReduceLROnPlateau: Автоматически снижает скорость обучения если потери не улучшаются (patience=5 эпох)
  • Stratified split: Сохраняет пропорции классов в каждом подмножестве
